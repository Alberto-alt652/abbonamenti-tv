# Analisi Piani Streaming TV

[readme.md](https://github.com/user-attachments/files/33516198/readme.md)

[![Demo Live](https://shields.io)](https://alberto-alt652.github.io/abbonamenti-tv/)

Un semplice archivio di dati che raccoglie e confronta i diversi piani di abbonamento delle principali piattaforme di streaming video (Netflix, Disney+, NOW).

## 📋 Contenuto del File
Il file include le seguenti piattaforme e i relativi livelli di abbonamento (Standard con pubblicità, Standard 1080p, Premium 4K+HDR):
- **Netflix**
- **Disney+**
- **NOW**

## 🚀 Come Utilizzare Questi Dati
Puoi usare questa lista come base per:
1. Sviluppare un'applicazione web di confronto prezzi.
2. Integrare un database per un bot di consigli streaming.
3. Creare una tabella comparativa in formato Markdown o HTML.

## 🛠️ Tecnologie Utilizzate
*   **HTML5:** Struttura semantica della pagina.
*   **CSS3:** Styling personalizzato, layout (Flexbox/Grid), animazioni e media queries per il responsive design.
*   **JavaScript (Vanilla):** Gestione di eventuali dinamiche interattive e logiche di click.


## 🛠️ Tecnologie Consigliate
Se vuoi trasformare questo file in un progetto software, ti consigliamo di usare:
- **Python / Node.js** (per il parsing dei dati)
- **JSON / CSV** (come formato di archiviazione strutturato)
